# Gemini model routing

## Conversation

Primary conversation model is configured as `gemini-flash-latest`.

Google defines the `latest` model pattern as an alias that is hot-swapped to the newest release for that model variation. This keeps the normal Home AI conversation path on the newest Gemini Flash without changing application code for each release.

Current fallback configuration:

1. `gemini-flash-latest`
2. `gemini-3.7-flash`
3. `gemini-3.6-flash`
4. `gemini-3.5-flash`
5. `gemini-3.5-flash-lite`
6. `gemini-3.1-flash-lite`

The fallback ladder is configuration (`GEMINI_FALLBACK_MODELS`), not response-logic hard-coding. The primary alias updates automatically; the explicit lower-model ladder remains configuration so its quality order is intentional and auditable.

## Quota fallback

A `429 RESOURCE_EXHAUSTED` response is **not retried against the same model**. The next configured model is attempted instead. This avoids multiplying requests after an RPM/RPD quota has already been hit.

Home AI persists a per-model quota block in D1 (`app_state`). Subsequent LINE requests skip a model that is already known to be quota-limited instead of probing it again on every message.

The 429 payload is inspected for Google quota IDs and `RetryInfo`:

- Per-minute/RPM blocks use Google's retry delay when available, otherwise a conservative one-minute window.
- Per-day/RPD blocks remain skipped until the next Pacific-time daily reset boundary.
- When the block expires, the higher model is automatically eligible again, so normal conversation naturally returns to the highest configured route.

## Timeout and upstream fallback

Quota exhaustion is not the only reason a model can become unusable for one request. A provider can accept a connection and then fail to produce a response promptly. Home AI therefore applies its own latency budget rather than relying on Cloudflare Queue's much larger platform wall-time allowance.

Default latency configuration:

```text
GEMINI_MODEL_TIMEOUT_MS=30000
GEMINI_REPLY_DEADLINE_MS=60000
GEMINI_DEEP_DEADLINE_MS=180000
GEMINI_MEMORY_TIMEOUT_MS=45000
LINE_API_TIMEOUT_MS=10000
```

Behavior:

- A conversation model gets at most 30 seconds; exact standalone greetings use 20 seconds per model and 35 seconds total.
- Normal processing reserves 20 seconds of its 60-second budget for delivery; generation and event search share the remaining absolute deadline. This is an application budget, not an external delivery guarantee.
- `/deep` gets at most 180 seconds total.
- HTTP 524 is treated as timeout-like failure.
- A timeout or transient upstream 5xx is **not persisted as quota exhaustion**. The next configured model can be tried while overall time remains.
- Conversation routing uses one transient attempt per model. Explicit unsupported Priority falls back to standard on the same model within the original deadline.

If a lower model answers successfully, LINE sends the result in this order:

1. A model-switch notice showing whether the higher route failed because of quota, timeout or temporary API failure.
2. The original answer generated by the lower model.

If all configured models are quota-blocked, Home AI sends the all-models-exhausted notice. If the ladder instead fails because of timeouts/upstream errors, Home AI sends a visible bounded-latency failure rather than staying silent.

## Long-term memory

Long-term memory extraction uses `GEMINI_MEMORY_MODEL`, currently `gemini-3.5-flash-lite`, independently from the conversation primary model. This keeps background memory summarization from consuming the newest Flash model's conversation quota.

Memory work runs on the separate `line-home-ai-memory` Cloudflare Queue. Therefore a slow memory extraction cannot occupy the single-concurrency LINE reply Queue.

If the memory model returns 429, the persistent per-model quota block is used and memory extraction is postponed. If the memory model times out or returns a transient 5xx, extraction is also postponed. The raw conversation remains stored and the memory cursor is not advanced, so a later successful maintenance pass can catch up.

## Cloudflare variables

```text
GEMINI_MODEL=gemini-flash-latest
GEMINI_FALLBACK_MODELS=gemini-3.7-flash,gemini-3.6-flash,gemini-3.5-flash,gemini-3.5-flash-lite,gemini-3.1-flash-lite
GEMINI_MEMORY_MODEL=gemini-3.5-flash-lite
GEMINI_MODEL_TIMEOUT_MS=30000
GEMINI_REPLY_DEADLINE_MS=60000
GEMINI_DEEP_DEADLINE_MS=180000
GEMINI_MEMORY_TIMEOUT_MS=45000
LINE_API_TIMEOUT_MS=10000
```

These are non-secret configuration variables. The API key remains only in the `GEMINI_API_KEY` Cloudflare Secret.

## Release 1.6.0

- Latest Flash remains primary. Conversation calls request Priority. Actual returned tier is logged separately; Google may downgrade to standard. No paid billing is enabled.
- HTTP response bodies are included in network deadlines, including LINE and file operations.
- Registered display names are read from D1; background memory work refreshes profiles. Uploaded-file deletion is delegated to the memory queue.
- Event search uses `gemini-3.8-live` with Google Search and audio transcription, a separate search model, not a claim that Live equals latest Flash. Audio is discarded. Search output requires actual grounding queries, citation support and source URLs; ungrounded output fails closed.
- The application search reservation cap is 450/day; this does not assert that Google grants 450 Live requests. Provider quotas still apply.
- Release diagnostics compare two standard and two Priority fixed public greetings, then perform one public Hamamatsu search. They run once per release and send no LINE messages. These small samples check functionality, not a latency SLA.
- Event queue concurrency remains one to preserve this single household's conversation processing. Parallelization without atomic ownership and per-chat ordering is not safe. Finite network budgets and off-queue cleanup limit avoidable blocking.
- Fallback remains a degraded availability mode. It is not an always-latest guarantee. External outages, rate limits and recipient connectivity prevent an unconditional immediate-delivery guarantee.
